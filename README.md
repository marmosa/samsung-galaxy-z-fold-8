Samsung Galaxy Z Fold 8 Website

About the project

This is a responsive product website created as part of an HTML and CSS school assignment.

The website presents a fictional Samsung Galaxy Z Fold 8 smartphone and includes a separate order page where users can select storage capacity and colour and enter their contact information.

Features

Product information and pricing

Responsive layout for desktop and mobile devices

Order form with customer information

Storage and colour selection

Navigation between the product and order pages

Technologies used

HTML5

CSS3

CSS Grid and Flexbox

CSS custom properties

Google Fonts (Roboto)

Git and GitHub

Project structure

index.html – Product page

order.html – Order page

css/styles.css – Website styling

assets/images/ – Product images

Disclaimer

This is a fictional website created for educational purposes. It is not affiliated with Samsung, and no real orders are processed.
